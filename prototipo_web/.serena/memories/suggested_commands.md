# Commands (Windows PowerShell)
From repo root:
- Install: `npm --prefix prototipo_web install`
- Dev: `npm --prefix prototipo_web run dev`
- Build/typecheck: `npm --prefix prototipo_web run build`
- Lint: `npm --prefix prototipo_web run lint`
From `prototipo_web/`: equivalent `npm run dev|build|lint|preview`.
- Search: `rg <term> prototipo_web/src`.
