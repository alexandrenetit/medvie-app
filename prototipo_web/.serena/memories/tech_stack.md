# Tech Stack
- TypeScript 5.6, React 18.3, Vite 5.4 ESM SPA.
- Tailwind CSS 3.4 + PostCSS/Autoprefixer.
- React Router 6 HashRouter.
- framer-motion 11, lucide-react, recharts.
- Fonts via Fontsource: Inter UI, Outfit brand headings, JetBrains Mono numeric/document values.
- npm package manager; package root `prototipo_web/`.
